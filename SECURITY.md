# Seguridad / Security

## Informar de una vulnerabilidad

No publiques secretos, claves, datos personales ni archivos del juego. Si el problema puede explotarse o afecta a la cadena de actualización/descarga, utiliza **Security → Report a vulnerability** en GitHub cuando la función esté disponible. Si no está disponible, abre una incidencia sin detalles explotables y pide un canal privado.

Indica versión o commit, Windows, pasos mínimos y alcance. No se garantiza una fecha de respuesta. Las versiones PREVIEW y EXPERIMENTAL pueden tener riesgos conocidos y no reciben la misma consideración que una versión STABLE.

## Reporting a vulnerability

Never publish secrets, keys, personal information, or game files. For exploitable issues or download/update supply-chain issues, use GitHub **Security → Report a vulnerability** when available. Otherwise open an issue without exploitable details and request a private channel.

Include the version or commit, Windows version, minimal reproduction steps, and impact. No response deadline is guaranteed. PREVIEW and EXPERIMENTAL builds may carry known risks and are not treated as STABLE releases.
