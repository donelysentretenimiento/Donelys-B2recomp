# Contribuir / Contributing

Se aceptan contribuciones en español o inglés. English follows the Spanish section.

## Español

1. Abre una incidencia o explica el problema y cómo comprobarlo.
2. Crea una rama desde la línea correcta: `main` para cambios estables; `hdr-nativo` para trabajo que depende de la preview HDR.
3. No mezcles documentación, launcher, constructor, HDR y correcciones independientes en el mismo commit.
4. Añade pruebas que no necesiten archivos del juego siempre que sea posible.
5. Ejecuta las comprobaciones pertinentes y describe exactamente qué probaste.
6. Abre una Pull Request; no incluyas claves, volcados, código generado del juego, partidas, mods sin permiso ni datos personales.

Conserva `LICENSE`, `NOTICE.md`, avisos existentes y atribuciones. Al contribuir aceptas que tu aportación se distribuya bajo GPL-3.0-or-later. No afirmes autoría sobre código ajeno.

## English

1. Open an issue or explain the problem and how it can be verified.
2. Branch from the correct line: `main` for stable changes; `hdr-nativo` for work depending on the HDR preview.
3. Keep unrelated documentation, launcher, builder, HDR, and runtime fixes in separate commits.
4. Add tests that do not require game files whenever possible.
5. Run relevant checks and state exactly what was tested.
6. Open a pull request; never include keys, dumps, generated game code, saves, unlicensed mods, or personal data.

Preserve `LICENSE`, `NOTICE.md`, existing notices, and attribution. Contributions are distributed under GPL-3.0-or-later. Do not claim authorship of third-party code.
