# Controllers

Configure the controller in the launcher. Mappings are stored in `config\controllers.ini`. The Insert menu uses L3+R3, the D-pad, and A/B when the device is mapped correctly.

For incorrect prompts or mappings, report the exact model, USB/Bluetooth connection, Windows version, and sanitized `controllers.ini`. Test once with Steam Input and other remappers disabled to isolate the cause. Do not claim a model is supported until it has been tested.
