# FAQ

## Does this include the game?

No. It requires extracted files from your own compatible copy.

## Which version works?

Only version 1.2, update v131072, Build ID `F19B2E01E1794F933A9720C1404BB6F6`, is documented and validated.

## Is the HDR preview stable?

It is not presented as stable. Technical tests pass, but broader display and driver validation is pending.

## Must I install Python or a compiler?

Not with the complete Builder package. A source checkout requires the dependencies in [Building](building.md).

## May I redistribute a modification?

The GPL permits modification and redistribution under its terms. Preserve licenses and attribution, provide corresponding source, and do not present an unofficial build as an official DONELYS release. See [TRADEMARKS.md](../../TRADEMARKS.md).
