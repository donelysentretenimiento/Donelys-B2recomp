# Mandos

Configura el mando desde el launcher. La asignación se guarda en `config\controllers.ini`. El menú Insert usa L3+R3 para abrirse, cruceta para navegar y A/B para aceptar o volver cuando el dispositivo está correctamente asignado.

Si los botones no coinciden, indica modelo exacto, conexión USB/Bluetooth, versión de Windows y contenido de `controllers.ini` sin datos personales. Prueba primero con Steam Input y otras capas de remapeo desactivadas para aislar el origen; después vuelve a activarlas si son necesarias.

La compatibilidad no debe darse por probada para un modelo que no se haya ensayado. Consulta [solución de problemas](problemas.md).
