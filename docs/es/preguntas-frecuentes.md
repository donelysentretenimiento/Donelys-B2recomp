# Preguntas frecuentes

## ¿Incluye el juego?

No. El proyecto necesita archivos extraídos de tu propia copia compatible.

## ¿Qué versión funciona?

Sólo está documentada y validada la versión 1.2, actualización v131072, Build ID `F19B2E01E1794F933A9720C1404BB6F6`.

## ¿La preview HDR es estable?

No se presenta como estable. Tiene pruebas técnicas, pero falta validación visual en más pantallas y controladores.

## ¿Necesito instalar Python o un compilador?

No con el paquete Builder completo. Para un clon de código fuente sí debes proporcionar las dependencias indicadas en [compilación](compilacion.md).

## ¿Dónde están las partidas?

Las ejecuciones normales y de pruebas pueden usar carpetas de usuario diferentes. Consulta el launcher y `scripts\play.ps1`; no borres `build\play\userdata` ni otras carpetas de usuario sin comprobarlas.

## ¿Puedo redistribuir una modificación?

La GPL permite modificar y redistribuir el código cumpliendo sus condiciones. Debes conservar licencias y atribuciones, proporcionar el código fuente correspondiente y no presentar tu versión como oficial de DONELYS. Consulta [TRADEMARKS.md](../../TRADEMARKS.md).
